# SQL Data Warehouse Project 🚀

Hello friends! 👋 Welcome to my SQL Data Warehouse project repository. This project is built to transform raw operational retail data into a structured analytical relational database for executive reporting and KPI monitoring.

---

## 🏢 Business Scenario
A retail organization wants to transform its operational data into an analytical relational database for executive reporting and KPI monitoring.

---

## 📋 Detailed Required Tasks
* **Normalize** the dataset into fact and dimension tables.
* **Create** primary and foreign key relationships.
* **Build** a star schema model.
* **Write** advanced SQL queries using joins, subqueries, CTEs, and CASE statements.
* **Develop** SQL views and stored procedures for KPI calculations.
* **Create** analytical reports for profitability, customer behavior, and sales trends.
* **Optimize** queries for performance.
   ---

## ⚙️ Technical Requirements
* Minimum **5** relational tables.
* At least **15** SQL queries.
* Minimum **3** JOIN operations.
* At least **2** CTEs.
* At least **1** stored procedure.
* At least **1** SQL view.
